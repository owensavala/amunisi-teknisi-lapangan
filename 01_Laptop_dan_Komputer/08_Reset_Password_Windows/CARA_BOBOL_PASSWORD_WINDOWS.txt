================================================================================
          CARA BOBOLL PASSWORD WINDOWS (RESET PASSWORD TANPA INSTALL ULANG)
================================================================================
File di folder ini:
1. Pasang_Bypass_Sandi.bat
2. Kembalikan_Sistem_Normal.bat

KONDISI DIGUNAKAN:
Saat pemilik laptop lupa PIN / Sandi Windows dan tidak bisa masuk ke Desktop.

LANGKAH STEP BY STEP:
1. Siapkan flashdisk installer Windows (Ventoy atau Windows Setup biasa).
2. Boot laptop ke flashdisk installer tersebut.
3. Di layar pertama pilihan bahasa instalasi ("Install Now"), tekan:
   [Shift + F10] untuk memunculkan jendela Command Prompt hitam.
4. Cari drive flashdisk tools ini (ketik D: atau E: lalu tekan Enter).
5. Masuk ke folder ini dan ketik:
   Pasang_Bypass_Sandi.bat
6. Setelah muncul tulisan sukses, cabut flashdisk dan restart laptop ke Windows biasa.
7. Di layar login Windows, klik ikon "Ease of Access" (Kemudahan Akses) di kanan bawah.
8. Command Prompt Administrator akan terbuka!
   Ketik perintah untuk ganti sandi:
   net user Administrator 12345
   (Ganti "Administrator" dengan nama user klien jika bukan admin, dan "12345" dengan sandi baru).
9. Login menggunakan sandi baru tersebut!
10. Setelah masuk Desktop, colok flashdisk ini lagi dan jalankan:
    Kembalikan_Sistem_Normal.bat
    (Wajib dijalankan agar ikon kemudahan akses kembali normal dan aman).

BATASAN & KONDISI GAGAL:
- TIDAK BISA jika partisi sistem C: dienkripsi penuh dengan BitLocker aktif
  (karena butuh recovery key 48 digit).
