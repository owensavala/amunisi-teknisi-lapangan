01. Persiapan_Ujian_ANBK_TKA.bat (Folder: 01_Ujian_ANBK_TKA)
--------------------------------------------------------------------------------
- FUNGSI:
  Optimasi massal 1-klik untuk laptop/PC yang akan dipakai ujian simulasi atau
  pelaksanaan resmi ANBK, TKA, CBT, atau Ujian Sekolah.
- KONDISI PENGGUNAAN:
  Dijalankan pada H-1 atau beberapa jam sebelum ujian dimulai di seluruh laptop
  klien/peserta agar laptop tidak sleep, tidak update tiba-tiba, dan kamera/Wi-Fi aktif.
- STEP BY STEP:
  1. Klik kanan pada file -> Pilih "Run as administrator".
  2. Jendela script akan memproses 7 langkah otomatis (Power plan high performance,
     mematikan service Windows Update, sinkron jam ke server lokal, reset Wi-Fi & kamera).
  3. Tunggu hingga muncul tulisan "[SUKSES]" dan tekan Enter untuk keluar.
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Tidak bisa memperbaiki kamera yang rusak fisik / kabel fleksibel putus di engsel LCD.
  * Jika laptop Dell kamera bertanda silang karena dinonaktifkan di BIOS, script
    ini tidak bisa menembus BIOS (Wajib tekan F2 masuk BIOS -> Enable Integrated Camera).

02. CrystalDiskInfo Portable (Folder: 03_Diagnostik_Hardware\CrystalDiskInfo)
--------------------------------------------------------------------------------
- FUNGSI:
  Membaca kesehatan fisik SSD dan Harddisk secara akurat berdasarkan S.M.A.R.T.
- KONDISI PENGGUNAAN:
  Saat laptop lambat (100% disk usage di Task Manager), sering freeze, bunyi tik-tik
  pada harddisk, atau sebelum teknisi menginstall ulang Windows (agar tidak sia-sia).
- STEP BY STEP:
  1. Buka folder CrystalDiskInfo, klik 2x pada "DiskInfo64.exe" (atau DiskInfo32.exe).
  2. Perhatikan kotak "Health Status" di bagian kiri atas:
     - BIRU (GOOD 100% / Normal): Penyimpanan sehat.
     - KUNING (CAUTION): Terdapat Bad Sector / Reallocated Sectors (Wajib backup data!).
     - MERAH (BAD): Drive rusak parah dan akan mati total dalam waktu dekat.
  3. Lihat "Total Host Reads/Writes" untuk melihat sisa umur pemakaian SSD.
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Tidak bisa mendeteksi drive jika kabel SATA / NVMe longgar atau mati total (No Disk).
  * Tidak bisa membaca info S.M.A.R.T. jika USB enclosure casing harddisk eksternal
    murahan tidak mendukung fitur bridge passthrough S.M.A.R.T.

04. Generate_Laporan_Baterai.bat (Folder: 03_Diagnostik_Hardware)

- KONDISI PENGGUNAAN:

08. Pasang_Bypass_Sandi.bat & Kembalikan_Sistem_Normal.bat (08_Reset_Password_Windows)
--------------------------------------------------------------------------------
- FUNGSI:
  Membobol PIN / Password Windows yang lupa tanpa instal ulang dan tanpa hapus data.
- KONDISI PENGGUNAAN:
  Saat pemilik laptop lupa PIN / Password dan tidak bisa login ke desktop.
- STEP BY STEP:
  1. Colokkan flashdisk installer Windows (Ventoy/installer), boot ke installer.
  2. Di layar pertama installer ("Install Now"), tekan Shift + F10 untuk buka CMD.
  3. Cari letak drive Windows (misal D: atau C:), lalu masuk ke flashdisk tools ini.
  4. Jalankan "Pasang_Bypass_Sandi.bat".
  5. Restart laptop masuk ke Windows normal klien.
  6. Di layar login, klik ikon "Kemudahan Akses" (Ease of Access / Utilman) di pojok kanan bawah.
  7. Jendela Command Prompt Administrator akan terbuka! Ketik: "net user NamaUser SandiBaru".
  8. Login menggunakan sandi baru tersebut.
  9. Setelah masuk Windows, jalankan "Kembalikan_Sistem_Normal.bat" untuk menutup pintu darurat.
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * TIDAK BISA jika drive sistem Windows dienkripsi penuh menggunakan BitLocker aktif
    (karena drive terkunci secara kriptografi tanpa Recovery Key 48 digit).

09. Pulihkan_Virus_Recycler_Base64.bat (Folder: 09_Penyelamat_Flashdisk)
--------------------------------------------------------------------------------
- FUNGSI:
  Memulihkan file flashdisk/harddisk yang diacak menjadi Base64 di folder RECYCLER.BIN
  oleh virus worm CEFHelper / AvastSvc dan menghapus payload virusnya.
- KONDISI PENGGUNAAN:
  Saat isi flashdisk/HDD eksternal berubah jadi shortcut, file asli hilang, memori

  1. Klik kanan -> Run as administrator.
  2. Masukkan huruf drive target (misal: E atau F atau G).
  3. Script akan memindahkan data dari folder sembunyi ASCII 160 (\xa0), mendekode
     nama file Base64 asli, dan membersihkan sampah shortcut.
  4. Data Anda akan kembali utuh di folder "DATA_DARI_RECYCLER".
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Tidak bisa mengembalikan file yang sebelumnya sudah di-overwrite / tertimpa data baru.
  * Tidak bisa memulihkan file jika virusnya adalah jenis Ransomware enkripsi AES/RSA
    (file berubah ekstensi menjadi .locked, .stop, dll).

01. Fix_Sharing_Printer_0x0000011b.bat
--------------------------------------------------------------------------------
- FUNGSI:
  Memperbaiki registry otentikasi RPC Windows agar printer yang dishare di jaringan
  bisa disambungkan oleh laptop/komputer lain tanpa ditolak error 0x0000011b / 0x00000709.
- KONDISI PENGGUNAAN:
  Saat komputer klien kantor/lab ingin menyambung ke printer bersama, tapi muncul error:
  "Operation failed with error 0x0000011b".
- STEP BY STEP:
  1. Jalankan script ini di Komputer Server (yang dicolok kabel USB printer). Pilih opsi [1] atau [3].
  2. Jalankan script ini di Laptop Klien (yang numpang nge-print). Pilih opsi [2] atau [3].

- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Komputer Server dan Klien wajib berada di dalam SATU JARINGAN LOKAL (subnet IP sama).
  * Jika firewall pihak ketiga (seperti antivirus kaspersky/avast) memblokir port 445/139,
    antivirus tersebut harus diizinkan secara manual.

02. Fastboot_Toolkit.bat
--------------------------------------------------------------------------------
- FUNGSI:
  Mengontrol HP Android di level Bootloader: membaca info hardware, Unlock Bootloader (UBL),
  dan melakukan Hard Reset (Wipe Userdata & Cache) dari PC.
- KONDISI PENGGUNAAN:
  Saat HP Android BOOTLOOP (mentok di logo), restart berulang-ulang, atau lupa pola
  tapi menu recovery fisik tidak bisa dibuka karena tombol volume rusak.

  2. Colokkan kabel USB ke laptop.
  3. Buka "Fastboot_Toolkit.bat" -> Pilih [1] Cek Perangkat (pastikan serial terdeteksi).
  4. Pilih [3] Hard Reset (Ketik YAKIN untuk konfirmasi).
  5. Pilih [7] Reboot Normal. HP akan menyala bersih seperti setelan pabrik!
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Tidak bisa melakukan UBL jika pabrikan HP mengunci server tokennya (seperti Huawei
    atau beberapa seri Oppo/Vivo modern yang butuh akun otorisasi server).
  * Hard Reset via Fastboot akan menghapus seluruh data HP (Foto, Chat, Aplikasi).

--------------------------------------------------------------------------------
01. Tarik_Crash_Log_Panic_Full.bat
--------------------------------------------------------------------------------
- FUNGSI:
  Menyedot seluruh file crash log dari memori iPhone ke Desktop untuk mendeteksi
  sparepart rusak penyebab iPhone restart sendiri setiap 3 atau 5 menit.
- KONDISI PENGGUNAAN:
  Saat iPhone klien normal beberapa menit, lalu tiba-tiba mati / reboot berkala.
- STEP BY STEP:
  1. Nyalakan iPhone, colok kabel Lightning/Type-C ke laptop.
  2. Klik "Trust / Percayai Komputer Ini" di layar iPhone dan masukkan PIN layar.
  3. Klik 2x "Tarik_Crash_Log_Panic_Full.bat".
  4. Buka folder hasil tarikan di Desktop, buka file "panic-full-....ips" pakai Notepad.
  5. Cari kata "missing sensor":
     - prs0       : Fleksibel lubang charger bawah rusak (Ganti Dock Charger).
     - mic1       : Fleksibel tombol on/off & flash atas rusak (Ganti Flex Power).
     - tg0b / tg0v: Sensor baterai rusak / konektor kendor (Ganti Baterai).
     - AOP PANIC  : Sensor speaker depan / Face ID terkena air.
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * iPhone harus bisa menyala minimal 1-2 menit untuk menekan tombol "Trust".
  * Jika iPhone mati total (tidak bisa nyala sama sekali), panic log tidak bisa ditarik.

--------------------------------------------------------------------------------
02. Menu_Servis_iPhone.bat -> Opsi: KELUAR DARI RECOVERY MODE
--------------------------------------------------------------------------------
- FUNGSI:
  Mengirim perintah "irecovery -n" ke chip iBoot untuk membatalkan loop Recovery Mode.
- KONDISI PENGGUNAAN:
  Saat iPhone nyangkut di logo kabel charger / logo iTunes/komputer dan menolak masuk menu.
- STEP BY STEP:
  1. Colokkan iPhone yang nyangkut di layar kabel ke laptop.
  2. Buka "Menu_Servis_iPhone.bat" -> Pilih menu [5] KELUAR DARI RECOVERY MODE.
  3. iPhone akan langsung restart dan menyala normal kembali ke menu tanpa hilang data!
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Jika sistem iOS di dalam iPhone memang sudah corrupt parah atau memori NAND rusak,
    iPhone akan tetap kembali ke recovery mode (Wajib di-flash ulang via iTunes/3uTools).

--------------------------------------------------------------------------------
03. Menu_Servis_iPhone.bat -> Opsi: CEK KESEHATAN BATERAI (CYCLE COUNT)
--------------------------------------------------------------------------------
- FUNGSI:
  Membaca sensor asli com.apple.mobile.battery untuk mengetahui Cycle Count baterai.
- KONDISI PENGGUNAAN:
  Saat membeli iPhone second atau klien ingin tahu kesehatan baterai yang sesungguhnya
  (karena persentase Battery Health di menu Pengaturan sering disuntik/dimanipulasi).
- STEP BY STEP:
  1. Colokkan iPhone (kondisi menyala dan di-Trust).
  2. Buka Menu Servis iPhone -> Pilih menu [2] Cek Kesehatan Baterai.
  3. Lihat angka "CycleCount" (jumlah berapa kali baterai dicas dari 0 sampai 100%).
     - 0 - 300 kali   : Baterai masih sangat bagus (Original/Fresh).
     - 300 - 600 kali : Baterai normal pemakaian wajar.
     - Di atas 800x   : Baterai sudah soak/wajib diganti.
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Jika baterai iPhone diganti baterai non-original tanpa memindahkan chip BMS ori,
    nilai CycleCount mungkin tidak terbaca oleh sistem lockdown Apple.

04. Cek_Chip_DFU_Recovery_irecovery.bat
--------------------------------------------------------------------------------
- FUNGSI:
  Membaca ECID, CPID prosesor Apple, dan status mode (DFU vs Recovery) langsung dari BootROM.
- KONDISI PENGGUNAAN:
  Saat iPhone mati total (layar hitam) untuk memastikan apakah mesin masih hidup
  di level chip atau motherboard mati total (short).
- STEP BY STEP:
  1. Colokkan iPhone ke laptop.
  2. Klik 2x file bat. Jika terdeteksi chip Apple (CPID: 0x80xx), berarti mesin masih
     hidup dan bisa dilakukan tindakan software/flashing.
- BATASAN & KONDISI TIDAK BISA BERJALAN:
  * Jika jalur USB lightning korslet atau jalur daya VDD_MAIN motherboard mati total,
    chip tidak akan mendapat daya dan tidak akan terdeteksi di laptop.
